# Abholnummer

**View-ID:** `v-pickup-code-dynamic` · Kundenseite  
**Stand:** 14.02.2026

---

## Konzept

Fullscreen-Anzeige der Abholnummer nach Bestellung. Groß, gut lesbar, Tap-to-Complete.

## Aufbau

- Große Abholnummer (z.B. #1A)
- Anbieter, Gericht, Abholzeit
- „Kollegen bescheid geben“, „Erledigt“

## Regeln

- Gut lesbar (mind. 72px für Nummer)

- Code bleibt dominant, Meta-Information und CTA-Bereich wurden auf konsistente Abstaende/Hierarchie harmonisiert.
